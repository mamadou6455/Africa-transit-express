# AFRICA TRANSIT EXPRESS - Landing Page

Landing page professionnelle pour l'entreprise AFRICA TRANSIT EXPRESS, spécialisée dans le transfert de colis à Bamako, Mali.

## 📋 Description

AFRICA TRANSIT EXPRESS est une entreprise basée à Bamako, Mali, qui offre des services de transfert de colis à l'intérieur et à l'extérieur du pays. Cette landing page présente leurs services, informations de contact et permet aux clients de les contacter facilement.

## 🚀 Fonctionnalités

### ✨ Caractéristiques principales
- **Design moderne et professionnel** avec une interface utilisateur intuitive
- **Responsive design** adapté à tous les appareils (mobile, tablette, desktop)
- **Animations fluides** et interactions utilisateur avancées
- **Formulaire de contact** avec validation en temps réel
- **Navigation smooth scrolling** entre les sections

### 📱 Sections incluses
- **Header** avec navigation responsive
- **Hero Section** avec message d'accueil percutant

- **À Propos** avec statistiques animées et localisation
- **Contact** avec formulaire interactif et coordonnées complètes
- **Footer** avec liens rapides et réseaux sociaux

## 🚀 Installation et utilisation

### Méthode 1: XAMPP (Recommandé)
1. Copiez le dossier `Landing_transfère de colis` dans `htdocs` de XAMPP
2. Démarrez Apache depuis XAMPP Control Panel
3. Ouvrez votre navigateur et accédez à: `http://localhost/Landing_transf%C3%A8re%20de%20colis/`

### Méthode 2: Serveur local simple
1. Ouvrez le dossier du projet
2. Faites un clic droit sur `index.html`
3. Choisissez "Ouvrir avec" > votre navigateur web

### Méthode 3: VS Code Live Server
1. Ouvrez le projet dans VS Code
2. Installez l'extension "Live Server"
3. Faites un clic droit sur `index.html` et choisissez "Open with Live Server"

## 🎨 Personnalisation

### Modification des couleurs
Les couleurs principales sont définies dans `styles.css` dans la section `:root`:

```css
:root {
    --primary-color: #2c3e50;    /* Couleur principale */
    --secondary-color: #e74c3c;  /* Couleur secondaire (rouge) */
    --accent-color: #f39c12;     /* Couleur d'accent (orange) */
}
```

### Modification du contenu
- **Informations de l'entreprise**: Modifiez les textes dans `index.html`
- **Coordonnées**: Mettez à jour les informations dans la section contact
- **Services**: Adaptez les descriptions des services selon vos besoins

### Ajout de pages supplémentaires
1. Créez de nouveaux fichiers HTML
2. Ajoutez les liens correspondants dans la navigation
3. Maintenez la cohérence du design en utilisant les mêmes classes CSS

## 🌐 Déploiement

### Pour un déploiement en production:
1. **Hébergement web**: Uploadez les fichiers sur votre serveur
2. **Domaine**: Configurez votre nom de domaine
3. **SSL**: Activez HTTPS pour la sécurité
4. **Backend**: Connectez le formulaire à un service d'envoi d'emails

### Services recommandés:
- Hébergement: Hostinger, Bluehost, ou serveur local
- Email backend: Formspree, Netlify Forms, ou PHP Mail
- Domaine: .ml pour le Mali ou .com

## 📊 Performance
